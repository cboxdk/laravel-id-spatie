# Extending & customizing

Everything is a container binding, so extension is just a binding your provider makes
after this package's.

- **[Custom group→role mapping](custom-group-role-mappings.md)** — add the SCIM
  directory-group→role bridge (`GroupRoleMappings`), which this package ships with environment and tenant fencing.
